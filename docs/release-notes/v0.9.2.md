# FluentHMI Studio v0.9.2

本次更新新增 Modbus 寄存器按位读写、设计器控件层级树、表达式常用数学函数与非阻塞异步导出，改进 CAN 监视筛选与表格横向滚动体验，并集中修复了稳定性、通信与更新保留等多项问题。

## Modbus 与 CAN 增强

- **Modbus 寄存器按位读写（#39）**：保持寄存器（03）和输入寄存器（04）绑定新增「位号」（0–15）；开关支持「保持寄存器位」写入，按钮支持置位 / 复位 / 取反位操作，工程数据点支持按位绑定与回写。位写入采用 03 读-改-写 + 06 回写并按寄存器排队执行，避免并发覆盖。
- **CAN 监视与收发体验（#1）**：CAN 报文监视器支持十六进制 ID 模糊匹配、ID 范围（如 `100-1FF`）与 DBC 报文名筛选；报文监视表、数据表格、报警列表、工程数据监视和周期任务列表支持 `Shift` / `Ctrl` + 鼠标滚轮横向滚动。
- **CAN 示例工程修正**：`12-CAN收发测试.uidp` 改为 CAN 1 发送、CAN 2 接收，消除双通道同时发同一 ID 引起的「来源不唯一」保护与读数冻结。

## 设计器、运行器与导出改进

- **控件层级树与右键菜单**：左侧面板新增「层级」树视图，支持拖拽重排、跨容器/分页移动、右键置顶/置底与切换分页；多选拖动与对齐去重修复。
- **可视化配置助手**：属性栏新增 S7 地址构建器与实时校验、Modbus 功能码筛选下拉与 32 位寄存器跨度提示、子编辑器按钮内联摘要，以及 CAN 信号选择弹窗搜索框；运行预览中保存数据点不再断开已有硬件连接。
- **运行器窗口与控件工具栏**：独立运行与导出应用的「工程数据监视」和「周期任务」按钮统一置于窗口标题栏右侧，不再占用画布空间或改变自适应缩放；实时曲线、数据表格、滚动日志、CAN 监视器新增暂停 / 清空 / 导出 CSV 工具栏，数值显示与仪表盘补齐等待/过期视觉态及故障提示 tooltip。
- **表达式与异步导出**：表达式新增 `abs`、`min`、`max`、`round`、`clamp` 函数；应用导出前置校验工程结构与全部图片/DBC 资源，支持已有目标覆盖确认与后台线程异步打包；主窗口左侧导航栏新增「最近打开」和「导出应用」，并支持拖拽 `.uidp` 文件打开。

## 稳定性、协议与在线更新修复

- **Windows 在线更新保留用户文件**：更新替换安装目录时自动保留用户自放文件与 CAN 驱动库（如 `zlgcan.dll`、`kerneldlls`），备份目录带时间戳避免覆盖，并对可能残留文件在重启后弹出保留提示；增加更新包写盘校验。
- **协议与通信加固**：修复 S7 断开及退出时的异步线程清理、读错误日志与重连解锁，点位无变化时跳过重复轮询推送；补齐 MQTT 报文大小上限、握手超时与 QoS 1/2 应答超时重试；修复 Modbus RTU/ASCII 请求超时清理与主/从队列上限；补齐串口参数校验、TCP 连接超时与 KeepAlive、SLCAN 显式 8N1 配置及非法监听地址拦截。
- **Linux 与独立运行器**：Linux 启动脚本仅在存在图形显示环境变量时设置 `QT_QPA_PLATFORM=xcb`，`.desktop` 支持 `%f` 文件关联；`FluentHMIRuntime` 独立打开 `.uidp` 时同步 Studio 主题强调色并对缺失文件明确报错。

## 工程兼容性

Studio 读取 UIDP 1.0–1.3，当前工程格式为 1.3。使用 Modbus 寄存器位绑定/写入或新增表达式数学函数的工程请使用 v0.9.2 或更新版本；通过新版 Studio 重新导出应用即可更新随附运行器。

## English

This update adds Modbus register bit read/write, a Designer widget outline tree, built-in expression math functions, and non-blocking async app export, improves CAN monitor filtering and horizontal table scrolling, and fixes multiple stability, protocol, and online-update issues.

### Modbus and CAN improvements

- **Modbus register bit read/write (#39)**: Holding register (03) and input register (04) bindings add a **Bit** (0–15) option. Switches support writing a holding-register bit, buttons support set / clear / toggle bit actions, and project data points support bit-level readback and write-through. Bit writes perform queued FC03 read-modify-write + FC06 updates per register to prevent clobbering.
- **CAN monitor and table scrolling (#1)**: The CAN monitor filter supports fuzzy hex ID matching, ID ranges (e.g. `100-1FF`), and DBC message names. Hold `Shift` or `Ctrl` while using the mouse wheel to scroll sideways in the CAN monitor, data tables, alarm list, project data monitor, and periodic task dialog.
- **CAN tutorial project fix**: Updated `12-CAN收发测试.uidp` to transmit on CAN 1 and receive on CAN 2 so dual-channel loopback no longer triggers `Ambiguous source` freezes.

### Designer, runtime, and export improvements

- **Outline tree and context menus**: Added an **Outline** tab beside the widget palette with drag-and-drop reordering, reparenting across containers and tab pages, and right-click z-order / tab actions. Fixed multi-select drag and parent-child alignment deduplication.
- **Visual configuration helpers**: Added an S7 address builder with live validation, Modbus function-code filter dropdown and 32-bit register span hints, inline summaries on sub-editor buttons, and search filtering in the CAN signal picker. Saving a data point from Preview no longer drops active connections.
- **Runtime title bar and widget toolbars**: Moved **Project data monitor** and **Periodic tasks** into the standalone window title bar so they never shrink or rescale the canvas. Added pause / clear / export CSV toolbars to charts, data tables, log boxes, and the CAN monitor, plus muted waiting/stale visuals and error badge tooltips.
- **Expressions and async export**: Added `abs`, `min`, `max`, `round`, and `clamp` expression functions. App export validates the project schema and all image/DBC assets upfront, supports overwrite confirmation with atomic swap, and runs in a background thread with a progress dialog. Added **Recent projects** and **Export app** to the navigation rail, directory persistence, and `.uidp` drag-and-drop opening.

### Stability, protocol, and updater fixes

- **Windows online update preservation**: Preserves user files and CAN driver DLLs (such as `zlgcan.dll` and `kerneldlls`) across online updates with timestamped backup folders and a startup notice, plus disk-write verification during download.
- **Protocol and link hardening**: Fixed S7 teardown races, read error logging, and card unlock on failure, and deduplicated unchanged S7 polling pushes; added MQTT packet size caps, handshake timeout, and QoS 1/2 ACK timeout/retry; fixed Modbus RTU/ASCII request timeout expiration and queue bounds; checked serial port parameter errors, added TCP connect timeout and keep-alive, rejected invalid TCP listen addresses, and set explicit 8N1 parameters for SLCAN.
- **Linux packaging and standalone CLI**: The Linux launcher sets `QT_QPA_PLATFORM=xcb` only when a display is present, `.desktop` includes `%f`, and standalone `FluentHMIRuntime` applies Studio's accent color and reports missing `.uidp` paths explicitly.

Studio reads UIDP 1.0–1.3. The current project format is 1.3. Use v0.9.2 or later for Modbus register bit bindings/writes or the new expression math functions, and re-export standalone applications to bundle the updated runtime.
