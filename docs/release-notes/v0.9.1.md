# FluentHMI Studio v0.9.1

本次更新修复多连接收发和重连的问题，并简化协议配置与验证步骤。

## 收发与绑定修复

- UDP 下发按配置的目标和子通道路由。TCP 服务端的绑定在断线后保留原来源，其他设备的回应不会接管其读数或触发报警。设备独占一个 IP 时，按 IP 绑定可在临时端口变化后恢复取值。
- Modbus 收发检查连接解析模式、应答来源和功能码。超时或异常时，只将对应地址块的读数标为旧值。
- HEX 工程数据点按配置的帧头筛选。收到其他命令字的报文时，原读数保留。匹配帧取值失败时可查看数据质量。

## 配置与示例

- HEX 按钮可按顺序混发多个模板，周期任务逐轮读取当前输入。数据发送卡可按模板字段填写，并在发送前查看组帧结果。
- Modbus 和 S7 可以选择工程数据点作为写入对象。CAN 初值映射与接收过滤、Modbus 从站初值和子通道提供选取或表格编辑入口。运行预览可从 CAN 信号和已匹配的 Modbus 读应答创建数据点。
- 数字时序图的逐路绑定扩至 32 路。运行时可滚动或筛选通道，导出包含全部已配置通道。
- 17 系列 13 个示例在画布内提供操作步骤，可以在运行预览中查看工程数据点。17.7 可以修改 CAN 转速与压力，17.10 可以修改周期混发的四项输入，17.11 可按字段发送虚拟串口报文。

## 工程兼容性

Studio 读取 UIDP 1.0–1.3，当前工程格式为 1.3。使用多模板混发或按工程数据点写入的动作在较早版本中保持停用。使用 32 路逐路绑定或更新后的 17 系列示例时，请使用 v0.9.1 或更新版本。通过新版 Studio 重新导出应用可更新随附运行器。

## English

This update fixes multi-connection routing and reconnection issues and makes protocol setup and verification easier.

### Routing and binding fixes

- UDP sends follow the configured destination and endpoint. TCP server bindings retain their original source after a disconnect, so replies from another device cannot take over readings or trigger alarms. When a device has a dedicated IP address, an IP binding can resume sampling after the device reconnects from a new ephemeral port.
- Modbus validates the connection's parser, response source, and function code. A timeout or exception marks only the affected address block as stale.
- HEX project data points filter frames by their configured header. A frame for a different command preserves the last reading. Data quality shows extraction failures for matching frames.

### Configuration and examples

- HEX buttons can send an ordered batch of frame templates, reading current inputs on each periodic cycle. Data send cards support entering template fields and previewing the resulting frame.
- Modbus and S7 support choosing a project data point as the write target. Visual editors cover CAN initial-state mapping and receive filters, Modbus slave initial values, and endpoint selection. Runtime Preview can create data points from CAN signals and Modbus responses matched to read requests.
- The timing chart supports up to 32 individually bound channels. Scroll or filter channels during a run and export all configured channels.
- All 13 Series 17 projects have on-canvas instructions and show project data points in Runtime Preview. Edit CAN speed and pressure in 17.7, change all four mixed-frame inputs during a periodic run in 17.10, or enter virtual serial frames by field in 17.11.

Studio reads UIDP 1.0–1.3. The current project format is 1.3. Older versions disable actions that depend on multi-template sends or writes through project data points. Use v0.9.1 or later for 32-channel bindings and the updated Series 17 projects. Re-export standalone applications to include the updated runtime.
