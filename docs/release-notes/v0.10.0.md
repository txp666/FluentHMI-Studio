# FluentHMI Studio v0.10.0

## 新功能

- **内置 AI 助手。** 在设计器中用自然语言描述想改的界面、协议解析或数据绑定。助手会列出工程改动，点击「应用到工程」后生效，也可以撤销。
- **可视化枚举与多状态小灯。** 在一张表里为设备状态码配置文字和颜色，小灯、数值状态徽标和下拉框均可引用。每盏灯还能按状态配置熄灭、常亮、慢闪或快闪。编辑器会标出所有重复的状态码，方便逐行修正。
- **统一的区间变色。** 数值卡、仪表和进度条按换算后的工程值选色，达到下限即切换。冷却站示例中，7.99 ℃ 为绿色，8 ℃ 和 9.99 ℃ 为黄色，10 ℃ 为红色。数值卡会显示阈值，遇到较长读数会自动缩小字号。
- **控件自定义操作。** 点击小灯、按钮或切换开关时，可根据当前值和工程数据跳转页面、设置参数、显示通知或发送命令。下拉框可用工程枚举中的设备码发送和回显。
- **独立应用的 CAN 库。** Windows 导出时可随包复制 Studio 或运行器旁已有的 ZLG、PCAN 驱动库。macOS 导出时可随包携带已有的 PCAN 兼容库。

Studio 可读取 UIDP 1.0 至 1.4，保存时按工程实际使用的功能选择格式。使用新控件功能的工程采用 UIDP 1.4，部署独立应用时请用此版 Studio 重新导出。[冷却站温控联调示例](https://github.com/txp666/FluentHMI-Studio/blob/v0.10.0/examples/industrial/冷却站温控联调.uidp)

## English

- **Built-in AI assistant.** Describe a layout, protocol parser, or data binding in the designer. Review the proposed changes, apply them to the project, and undo them if needed.
- **Visual enums and multi-state indicators.** Map device codes to labels and colors in one table shared by indicators, status badges, and choice controls. Set each indicator to off, steady, slow blink, or fast blink for each state. The editor highlights every entry that shares a duplicate code.
- **Range colors.** Numeric cards, gauges, and progress bars change color when the converted reading reaches a lower bound. In the cooling station example, 7.99 °C is green, 8 °C and 9.99 °C are yellow, and 10 °C is red. Numeric cards show their thresholds and reduce the font size to fit long readings.
- **Custom control actions.** Indicator clicks, button clicks, and switch transitions can navigate to a page, set a parameter, show a notification, or send a command. Actions can depend on the current value and project data. Choice controls can send and display device codes from a shared enum.
- **CAN libraries in exported apps.** Windows exports can include ZLG and PCAN libraries found alongside Studio or the runtime. macOS exports can include an available PCAN-compatible library.

Studio reads UIDP 1.0 through 1.4 and chooses the format on save according to the features used. Projects using the new widget features use UIDP 1.4. Re-export standalone apps with this version to include the updated runtime. [Cooling station example](https://github.com/txp666/FluentHMI-Studio/blob/v0.10.0/examples/industrial/冷却站温控联调.uidp)
