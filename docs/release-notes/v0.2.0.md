本版本面向 PLC 和各种自定义协议的设备：Modbus 补齐了按地址取值、多寄存器写入和轮询表，新增可配置长度字段和校验的二进制帧解析、可配置结束符和编码的文本解析，以及 Modbus ASCII。表达式求值器补齐了位运算和比较。所有规则与 PyQt UI Designer 0.2.0 逐条一致，并用同一批字节流在两个程序上对拍过。

- Modbus：读响应按寄存器地址命名（`hr100`、`ir0`、`co3`、`di0`），绑定和曲线新增"寄存器区"选项，轮询多块地址时不再分不清是哪块的响应；按钮、开关、滑块、数值框可以发 FC16 写多个寄存器，值的类型（uint16 / int16 / uint32 / int32 / float32）和寄存器序可选。Modbus 卡片新增轮询表（多行 `从站,功能码,地址,数量`）和响应超时，一次只发一条请求，状态显示"轮询正常 · N/M"、无响应的条目和设备返回的异常码。
- 二进制帧（`hex` 解析模式）：帧头、帧尾可以只填一个或都不填，新增长度字段（偏移、字节数、字节序，长度数的是数据 / 长度字段之后 / 整帧）、固定帧长、和校验 / 异或 / CRC8 / CRC16-Modbus / CRC16-CCITT 校验（可设起点和字节序）、空闲超时分帧；字段表支持字节序和 uint8 … float64、ASCII、HEX 十种类型。用 `hex` 模式的链路把整帧交给 HEX字节提取 和曲线，控件上不必再填帧头帧尾。
- 文本（`line` 解析模式）：行结束符、键值分隔符（`=` 或 `:`）和编码（UTF-8 / GBK / ASCII）可配，坏字节的替换规则与 Python 版逐字节相同；`$…*HH` 的 NMEA 语句自动校验；JSON 不再要求一行一条，多行格式化、连着发、顶层数组都能解析。GBK 需要带 ICU 的 Qt，发布包已包含。
- 新增 Modbus ASCII 解析模式 `modbus_ascii`，Modbus 命令在这类链路上自动按 ASCII 组帧；新增 FC 07、08、17、22、23 响应的解析。
- 表达式：`value & 1`、`(value >> 1) & 1`、`value * 3.3 / 4095 < 1`、`0 < value < 40`、`and` / `or` / `not` 都能算了，运算符和优先级与 Python 一致，比较结果按 True / False 绑定给指示灯。
- 设计器：工程设置的「默认帧格式」覆盖全部解析选项，串口 / TCP / MQTT 卡片可以各自设置帧格式（`parserConfig`）；Modbus 模式的发送设置不再随"发送开关"隐藏。
- 显示：数据接收卡片按链路的编码显示文本，GBK 设备的日志不再乱码；"自动"显示格式去掉二进制运算的尾数噪声（`26.700000000000003` 显示为 `26.7`）。
- 新增示例 `examples/tutorials/10-PLC恒压供水.uidp`：Modbus TCP 轮询、按地址绑定、float32 写入。
- 文档：`docs/uidp-format.md` 补全解析模式的全部键，`docs/uidp-widgets.md` 重新生成。

`.uidp` 文件向后兼容：旧工程的 `hex` 配置（只有帧头、帧尾、字段表）和 Modbus 绑定按原样工作。

提供 Windows x64 和 macOS universal 独立运行包及 SHA-256 校验文件，包内只有一份 Qt，导出的应用可直接拷到别的电脑上运行；Mac 包只做了 ad hoc 签名，第一次打开需要在"系统设置 → 隐私与安全性"中点"仍要打开"，Windows 包未做 Authenticode 签名。预发布版本不会通过应用内的"检查更新"推送。
