- CAN / CAN FD：新增 CAN 配置卡片，支持 PCAN（Windows、macOS）、致远 ZLG（Windows）、SocketCAN（Linux）和 slcan 适配器，波特率可按采样点设置。收到的报文用 DBC 文件或卡片上写的信号解码，绑定、曲线和表格照常使用。
- 控件可以按 DBC 信号发 CAN 报文，单次或周期发送；新增报文监视控件，可按 ID 和类型筛选、按列排序；数据发送卡片在 CAN 链路上发 `ID#数据`。
- 控件和实时曲线可以直接按 CAN ID、起始位、长度绑定信号，字节序支持 Intel、Motorola MSB、Motorola LSB。
- 新示例「12-CAN收发测试」（examples/tutorials 下）：两张 CAN 卡接在同一条总线上互相收发。
- 滑块可以在两端显示最小值和最大值（属性「显示上下限」，默认关闭）。
- 修复 Linux 版在 Ubuntu 26.04 上启动时崩溃。

## English

- CAN / CAN FD: a new CAN card for PCAN (Windows, macOS), ZLG (Windows), SocketCAN (Linux) and slcan adapters, with the bitrate set by sample point. Received frames decode through a DBC file or signals written on the card, so bindings, charts and tables work as before.
- Widgets send CAN frames by DBC signal, once or cyclically; a new CAN monitor widget that can be filtered by ID and type and sorted by column; the data send card sends `ID#DATA` on CAN links.
- Widgets and chart curves can bind a signal directly by CAN ID, start bit and length, in Intel, Motorola MSB or Motorola LSB byte order.
- A new example, 12-CAN收发测试 (in examples/tutorials): two CAN cards on one bus sending to each other.
- Sliders can show their minimum and maximum at the ends (the "Show limits" property, off by default).
- Fixed the Linux version crashing at startup on Ubuntu 26.04.
