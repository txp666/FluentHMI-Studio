# FluentHMI Studio 0.7.0

- Add classic Siemens S7comm connections through the official Snap7 library. Configure independent PLC connections, typed DB/M/I/Q bindings, charts and targeted writes in Preview and exported applications. BOOL writes preserve neighboring bits. S7 projects use UIDP 1.1; ordinary projects retain 1.0. See [S7 setup and limits](https://github.com/txp666/FluentHMI-Studio/blob/main/docs/s7.md).
- Add a scrolling CAN frame log alongside the per-ID summary, with timestamps, optional automatic scrolling and a configurable retention limit of 1–50000 records.
- Export retained CAN records to UTF-8 CSV using the active filter/sort, including full CAN FD payloads and optional decoded signals. Available in Preview and standalone exported applications.
- Link [FluentPLC Simulator](https://github.com/txp666/FluentPLC-Simulator) beside the S7 setup and example in both READMEs.
