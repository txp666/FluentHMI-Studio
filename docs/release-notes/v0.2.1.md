- Modbus 自动轮询：Modbus 卡片新增「轮询方式」（`pollMode`，默认"自动"）和「连接后自动轮询」（`autoStart`，默认开）。自动方式下不用写轮询表，卡片按控件的 Modbus 绑定和实时曲线的 Modbus 曲线规划读取：同一从站、同一功能码里相近的地址合并成一块（寄存器间隔 ≤ 8、一块 ≤ 120 个，线圈和离散输入间隔 ≤ 64、一块 ≤ 1000 个），每块按绑定新增的「采集周期(ms)」（`mbPeriod`，0 用卡片的轮询 ms）读取，只读界面上看得见的控件，选项卡其他页上的不读。每条链路有一个 Modbus 主站队列，一次只有一个请求在线上，写命令排在读请求前面，轮询中按按钮写入不会再和在途的读请求撞车。状态栏显示"自动 · N 块 · 正常"、无响应或返回异常的块，鼠标悬停列出各块的从站、功能码、地址和周期。规划规则与 PyQt UI Designer 用同一份向量文件（`tests/data/poll_plan_vectors.json`）测试。
- 应用标识改为 `io.github.txp666.FluentHMIStudio` / `io.github.txp666.FluentHMIRuntime`（导出的应用为 `io.github.txp666.fluenthmi.app…`）。macOS 会把新版当成一个新应用，偏好设置会重置一次。

`.uidp` 文件向后兼容：没有 `pollMode` 的旧工程按"轮询表"方式打开，且不自动开始轮询（`autoStart` 按 `false`），和之前一样点「轮询」才开始，状态文字与之前相同；示例 `examples/tutorials/10-PLC恒压供水.uidp` 未改动。
