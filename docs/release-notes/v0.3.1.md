- 导出的应用使用导出时 Studio 的主题色和浅色 / 深色模式，与设计时看到的一致。
- 导出的 Windows 程序，版本信息（产品名、文件说明、文件名）改为应用自己的名字，不再显示 FluentHMI Studio。

## English

- Exported apps start in the Studio's theme colour and light / dark mode as set at export time, matching what you designed.
- Exported Windows programs' version information (product name, description, file name) names the app instead of FluentHMI Studio.
