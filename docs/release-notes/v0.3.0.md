- 设计器支持撤销 / 重做（最多 100 步）和复制 / 粘贴；剪贴板与 PyQt UI Designer 互通，也能直接粘贴按 `.uidp` 格式写的控件 JSON。
- 工具栏改为图标按钮，与 PyQt UI Designer 的按钮和顺序相同；两端的开关可隐藏或显示控件库和属性面板。控件库图标重画，链路卡片、收发卡片和日志框归入「通信控件」。
- 工程可以设置应用图标（`.uidp` 的 `icon`），导出的应用用它做窗口、任务栏和程序图标。
- 实时曲线保存完整历史记录，支持游标、CSV / JSON 保存和加载对比曲线；读数显示在曲线上方，曲线占满宽度，刻度取整。
- 设置页新增主题色和云母效果（Windows 11）。
- 修复：Modbus 轮询按时读取每一块；日志框按设备发送的顺序列出字段；连接后链路卡片锁定连接参数。
- 改用 Qt 6.12 和 FluentQtWidgets 0.3.2。

## English

- The designer has undo / redo (up to 100 steps) and copy / paste, with a clipboard PyQt UI Designer shares; widget JSON written in the `.uidp` format pastes too.
- The toolbar shows icons, the same buttons in the same order as PyQt UI Designer's, with switches at its ends that hide or show the palette and the property panel. The palette has redrawn icons, and the link cards, send/receive cards and log box are grouped as 通信控件.
- A project can name an app icon (`icon` in `.uidp`); exported apps use it for the window, the taskbar and the program file.
- The real-time chart keeps its whole history, with a cursor, CSV / JSON saving and a loaded run to compare; its readings sit above the plot, which takes the full width, on round ticks.
- Settings add a theme colour and Mica (Windows 11).
- Fixes: Modbus polling reads each block on time; the log box lists fields in the order the device sent them; link cards lock their connection settings while connected.
- Built on Qt 6.12 and FluentQtWidgets 0.3.2.
