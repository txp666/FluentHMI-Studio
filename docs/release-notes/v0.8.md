# FluentHMI Studio v0.8

v0.8 加入多通道通信、工程数据点与报警，并扩展 CAN、分页和常用控件的配置。设计器预览和导出的独立应用共用这些运行功能。

[操作图解与示例工程](https://github.com/txp666/FluentHMI-Studio/blob/v0.8/docs/tutorials/v0.8-guide.zh.md)

## 新增功能

- 控件、曲线和日志可**指定接收来源**，命令可指定发送连接。TCP 服务端、UDP 和 MQTT 可进一步区分客户端、对端地址或 Topic。Modbus 主站按连接和对端分别排队，各连接可设置轮询周期和响应超时。
- ZLG USBCAN-I/II 支持**采样点、自定义位时序和内置 BTR 计算器**。其他支持的 ZLG 型号可粘贴对应的 ZCANPRO 计算结果。新增 USBCAN-E-mini 型号选项、设备或通道搜索、通道负载估算和适配器支持时的 Bus-off 自动恢复设置。
- CAN 支持**从反馈初始化发送报文**，可按报文或信号配置映射。首次控制发送用近期有效反馈初始化已映射的位，随后沿用该连接的发送缓存。适合多路输出共用一帧的场景。
- **CAN 自动保存**在后台按行数分割 CSV，保存所选连接的收发报文。文件分段大小单独设置，表格筛选和显示行数不影响自动保存范围。
- **工程数据与报警**统一定义接收数据点、跨点表达式和分级报警。支持当前报警和本地历史、确认、消音、通知与 CSV 导出。列表可按关键词、级别、状态、事件和时间筛选，自定义时间支持 Fluent 日历、独立时间选择和键盘输入。
- 分页容器有**四种导航风格**，可添加、删除、重命名和排序页面。新增按钮与卡片外观、整数或小数数值框、下拉／分段／单选组、开关／复选框样式，以及数值枚举与状态徽标。工业控件的标题与读值可分别隐藏、定位，并可锁定文字位置。动力电池可按阈值分段变色。
- 复杂配置字段旁的**圆形信息图标**打开可复制示例的帮助卡片。随包提供工程数据与报警、分页与控件风格、输入与状态筛选三个示例。

## 问题修复与体验改进

- ZLG USBCAN-I/II 通道跳过可能长时间阻塞接收的状态回读，保留错误查询。CAN 通道在后台连接和断开，各通道独立接收，减少驱动等待造成的界面卡顿。不同连接的收发记录分别归属，按 ID 汇总时也按来源区分。
- 断开或 Bus-off 时丢弃尚未提交的 CAN 发送任务，映射后的控制值在驱动或适配器接受发送后才更新。旧工程的 ZLG 连接继续沿用相同波特率的设备标准位时序。
- CAN 报文监视增加序号，导出的 CSV 使用可读的毫秒时间，同时保留原始时间戳。滚动模式隐藏周期和次数，汇总模式隐藏自动滚动。
- 录制报文时可打开或更换自动保存目录。切换 CAN 型号后只显示适用的位时序、FD 和终端电阻选项。
- 旧版工程和剪贴板内容按原版本读取。明确选定连接时只向对应链路发送，Modbus 读取失败只将相应来源和地址块的工程点标为未知。
- 切换收发连接时清除原子通道。连接卡片的「跟随工程」显示实际解析模式，继承 Modbus 时仍可以设置该卡片的轮询参数。
- 同一工程在多个运行实例产生的报警历史会合并保存。历史页可导出筛选结果或全部历史，时间筛选覆盖截止秒内全部记录。紧凑画布上的筛选使用独立弹窗。
- 分页属性区分别设置当前编辑页和运行时启动页。点击画布上的页签只改变编辑页。
- 曲线右键菜单按窗口坐标弹出，保持正常大小并避免被缩放画布裁切。工业读值的重复悬浮提示改为按需开启。
- 连接卡片按可见字段安排高度，连接异常使用应用内通知。工程数据、帮助和位时序等弹窗统一使用 Fluent 控件。

工程格式与软件版本分开。已有功能沿用 UIDP 1.0／1.1，显式路由使用 1.2。CAN 发送初值映射、ZLG 自定义时序、工程数据、报警、枚举和小数输入等功能使用 1.3。使用 UIDP 1.2／1.3 的工程需用 FluentHMI Studio v0.8 或更高版本打开。[UIDP 工程格式](https://github.com/txp666/FluentHMI-Studio/blob/v0.8/docs/uidp-format.md)

## English

FluentHMI Studio v0.8 adds multi-channel communication, project data and alarms, and more CAN and widget configuration in Preview and exported applications.

[Illustrated guide and examples](https://github.com/txp666/FluentHMI-Studio/blob/v0.8/docs/tutorials/v0.8-guide.en.md)

### New features

- Route data bindings, charts, logs and commands to individual connection cards. TCP servers, UDP and MQTT also support peer or topic selection. Modbus polling runs per connection and peer, with polling periods and timeouts set on each connection.
- Configure sampling points and custom bit timing for ZLG USBCAN-I/II with the built-in BTR calculator. Paste ZCANPRO timing for other supported models. Discover device or channel options, select USBCAN-E-mini, view estimated bus load and opt into Bus-off recovery on supported adapters.
- Initialize mapped CAN control bits from recent feedback on the first send, then retain the per-connection transmit image. Record selected channels to segmented CSV files in the background with a separate rows-per-file limit.
- Define shared project points, expressions across points and alarm levels. Use the current alarm list, local event history, acknowledge, silence, notifications and CSV export. Filter by text, level, state, event and time. Enter dates and times with the Fluent calendar, time picker or keyboard.
- Choose from four page navigation styles and manage pages in the designer. Customize button and card styles, decimal inputs, selectors, checkboxes and enum status badges. Position or hide industrial titles and readings separately, lock the text positions, and set battery colors by charge level.
- Open field help and copyable examples from the circled information icon. Three bundled projects demonstrate project data and alarms, navigation and widget styles, and inputs and alarm filters.

### Fixes and refinements

- Skip the slow channel-status call on ZLG USBCAN-I/II while keeping error queries. Open and close CAN channels in the background and poll receive data per channel. Track frame direction and statistics separately by connection.
- Discard pending CAN sends on disconnect or Bus-off. Update mapped control values only when the driver or adapter accepts the frame. Keep the established ZLG bit timing for older projects that use device defaults.
- Add frame sequence numbers to the CAN monitor and readable millisecond timestamps to CSV exports. The CSV also retains the raw timestamp. Hide period and count in scrolling mode and auto-scroll in summary mode.
- Open or change the CAN recording folder during capture. Show only the bit timing, FD and termination settings supported by the selected CAN model.
- Read older projects and clipboard content according to their original format. Route explicitly targeted commands to the selected connection and mark only the affected project points unknown when a Modbus read fails.
- Clear the old endpoint when switching a send or receive connection. Show the inherited parser and keep the card's own Modbus polling options available.
- Merge alarm history from concurrent instances of the same project. Export either the filtered results or the full history. Include every record in the final second of a range, and open the filter panel separately on compact canvases.
- Set the page being edited and the runtime start page separately. Clicking a tab on the canvas changes the editing page.
- Keep chart context menus at normal size when the canvas scales. Make industrial hover readings optional, tighten connection card layouts, and show connection errors in in-app notifications.

UIDP 1.2 and 1.3 projects require FluentHMI Studio v0.8 or later. Projects that only use UIDP 1.0 or 1.1 features keep the corresponding format. [UIDP format guide](https://github.com/txp666/FluentHMI-Studio/blob/v0.8/docs/uidp-format.md)
