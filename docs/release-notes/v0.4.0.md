- Linux 版：Studio 提供 x64 和 arm64 的 .deb（Ubuntu 24.04 及以上、Debian 13、Raspberry Pi OS trixie），可以在应用内更新。在 Linux 上导出的应用是一个 tar.gz，解压后用 `start.sh` 启动。串口没有权限时，提示要加入哪个用户组。
- Modbus RTU / TCP 从站：串口、TCP、UDP 卡片可以当从站，应答外部主站；新增从站寄存器表控件和示例「11-温控仪模拟器」。
- 新增 UDP 链路卡片。
- 发命令新增 JSON 模式，按模板发送，自动转义。
- 图片显示新增旋转、水平 / 垂直镜像和缩放方式。
- 界面支持中文 / English 切换。默认跟随系统，英文系统下显示英文，可在设置 → 语言改回中文。导出的应用使用导出时的语言。
- 悬停提示改用 Fluent 组件。

## English

- Linux: Studio comes as a .deb for x64 and arm64 (Ubuntu 24.04 or later, Debian 13, Raspberry Pi OS trixie) and updates itself from the app. An app exported on Linux is one tar.gz; unpack it and run `start.sh`. When a serial port is denied, the message names the group to join.
- Modbus RTU / TCP slave: serial, TCP and UDP cards can answer an external master, with a new slave register table widget and the example "11-温控仪模拟器".
- A new UDP link card.
- A JSON send mode for commands, built from a template and escaped automatically.
- Image displays gain rotation, horizontal / vertical mirroring and a scale mode.
- The interface switches between Chinese and English. It follows the system by default, so an English system shows English; change it under Settings → Language. Exported apps use the language set at export time.
- Tooltips use Fluent components.
