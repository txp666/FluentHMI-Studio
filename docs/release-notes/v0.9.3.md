# FluentHMI Studio v0.9.3

本次热修版本修复导出应用中打开「工程数据监视」时出现卡顿或卡死的问题，并优化独立运行窗口的渲染性能。

## 修复与优化

- **修复导出应用「工程数据监视」卡顿 / 卡死**：将「工程数据监视」改为独立的 Fluent 顶层窗口（与主画布 `QGraphicsView` 解耦，可自由拖动、缩放并随主窗口自动关闭），避免半透明遮罩叠加在缩放画布上引发全窗口级联重绘。
- **高频数据刷新节流与单例防重**：工程数据监视改为 150 ms 合并刷新、仅更新有变化的单元格，列宽仅在打开时自动计算一次（取消实时 `ResizeToContents` 抖动），重复点击复用已有窗口；「周期任务」弹窗同步补齐单例防重与稳定列宽。
- **独立运行窗口渲染优化**：导出应用主窗口改为遵循配置决定是否启用 Windows 11 Mica（默认关闭，与 Studio 预览一致），为画布视图启用 `SmartViewportUpdate`，并在窗口缩放时保持活动弹窗位于标题栏之上。

## 工程兼容性

Studio 读取 UIDP 1.0–1.3，当前工程格式为 1.3。通过 v0.9.3 重新导出应用即可包含最新的运行器修复。

## English

This hotfix release fixes lag and freezes when opening the Project Data Monitor in exported standalone applications and improves runtime window rendering performance.

### Fixes and improvements

- **Fixed Project Data Monitor lag/freeze in exported apps**: Moved Project Data Monitor into an independent Fluent top-level window decoupled from the scaled `QGraphicsView` canvas (movable, resizable, and automatically closed with the host window), avoiding translucent overlay compositing storms over the HMI canvas.
- **Throttled updates and singleton reuse**: Coalesced live updates on a 150 ms timer, updated only changed cells, sized columns once on open instead of live `ResizeToContents`, and reused an already open monitor window. Applied singleton reuse and stable column widths to the Periodic Tasks dialog as well.
- **Runtime window rendering**: Exported app windows now follow the studio Mica setting (off by default on Windows 11) instead of forcing Mica on, enable `SmartViewportUpdate` on the scaled canvas view, and keep active overlay dialogs above the title bar on resize.

Studio reads UIDP 1.0–1.3. The current project format is 1.3. Re-export standalone applications with v0.9.3 to include the updated runtime fixes.
