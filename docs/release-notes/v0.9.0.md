# FluentHMI Studio v0.9.0

v0.9 把设备协议、数据取值、下发和运行调试连成一条工作流。工程帧模板可以在接收连接、数据点和发送控件间复用。新版同时更新了属性区、周期任务、诊断日志和配套实训。

## 新功能

- **共享帧模板。** 在工程中定义 HEX 或文本／JSON 格式。彩色预览标出字节位置、长度范围与校验范围。连接可混收多个 HEX 模板，按帧头或命令字区分，随后各自按长度与校验规则解析。预览会自动匹配粘贴的报文并保留输入。
- **CAN 和 HEX 位图。** 在 CAN 配置卡中按报文 ID 查看 DBC 或编辑内联信号，粘贴样例核对位和解析值。数据点、实时曲线和时序图共用 CAN 信号选择器。串口、TCP 和 UDP 共用的 HEX 模板也可按位查看，点击字段和位图可互相定位。
- **按字段发送。** 按钮和输入框可直接从模板组帧，共用命令字、字节序、默认值及校验。缺少必填字段时提示具体字段。修改模板可先查看影响范围，确认字段改名后迁移能明确对应的引用。
- **统一发送设置。** 在一个窗口新建或选择输入框、调整发送内容和看预览。文本、JSON、HEX 和原始 CAN 支持组合多个值。Modbus FC16 显示逐项寄存器范围，S7 使用单值写入表单。下发可启用确认和详细信息。
- **周期任务。** 按钮和数据发送卡按各自的间隔运行，每轮读取当前输入或已提交的工程参数。运行预览和独立应用可跨页查看任务状态、提交次数和跳过原因，并停止所选或全部任务。
- **工程数据。** 数据点供显示、曲线、记录、报警和命令复用。支持工程参数、数据有效期和引用查询。运行监视显示来源、采样时间和质量。模板字段也可直接绑定显示控件和实时曲线。
- **数字时序图。** 支持状态字和逐路绑定。每路可选 CAN 信号或工程数据点，共用时间轴，失效时该路留空。可自定义时间窗、用游标读值、导入和导出 CSV／JSON，并自动记录 CSV。
- **17 系列实训。** 新增 13 个工程，覆盖 TCP、UDP、虚拟串口、虚拟 CAN、Modbus 和 MQTT，分别练习单发、回读、分帧、坏帧恢复、模板混收及周期停止。

## 修复和体验改进

- 属性区分为常规、操作与发送、接收与绑定。选项随当前模式变化，切回可继续使用已保存的配置。开关支持独立的开启和关闭判定。
- 多连接发送按连接及子通道校验目标。设备点区分来源歧义、旧值和换算失败。同一帧的多个值先应用到数据点，再计算报警。已配置远端发送的控件不会顺便写入本地从站表。
- 接收帧格式切换前显示影响清单，保留的模板字段会迁移引用。连接卡更换时清理不适用的旧子通道。
- CAN 内联信号改名前可查看受影响的绑定和发送配置，确认后更新能明确对应的引用。发送时拒绝同一报文中互相冲突的重叠位赋值。
- CAN 监视在隐藏页继续接收，切回时更新可见行。数据接收卡每 40 ms 批量更新显示。开启自动滚动时，上翻暂停跟随，回到底部恢复。报文显示偏好在已保存工程的预览和独立应用中分别记住。
- 17.10 本机 TCP 回环在保留两张日志卡时以 6,000 帧/秒持续 30 秒，共解析 180,000 帧。停止周期任务后保留背景流量，未观察到后续周期报文。

## 从 v0.8 升级

Studio v0.9.0 可读 UIDP 1.0–1.3。共享帧模板、新发送表单和周期配置使用 UIDP 1.3。打开旧工程后检查只读输入、禁发设置、发送目标、旧下拉选项和记录列。使用手工发送 CAN 的数据发送卡可在新版选择 CAN 数据格式。已导出的应用可用新版 Studio 重新导出以更新随附运行器。

## English

Version 0.9 connects protocol setup, data binding, sending, and troubleshooting in one workflow.

### New features

- **Shared frame templates.** Define HEX or text/JSON formats once for connections, data points, and send controls. Visual previews show fields, the bytes counted by length, and checksum coverage. A connection can receive multiple HEX layouts, identify them by header or command bytes, and apply each layout's own framing and checksum. The preview preserves a pasted frame when choosing its matching template.
- **CAN and HEX bit maps.** Open a CAN card to browse DBC signals or edit inline signals by message ID, then paste a sample to check the bits and decoded values. Data points, real-time curves, and timing channels share a CAN signal picker. In shared HEX templates for serial, TCP, and UDP, click a bit or a field to highlight its counterpart.
- **Field-based sends.** Bind inputs, project points, or constants to template fields. Reuse field defaults and checksums, and identify missing required values before sending. Review affected connections, points, and controls before saving template changes. Confirmed renames update unambiguous references.
- **Send configuration.** Create or select inputs, assemble the command, and preview bytes in one editor. Text, JSON, HEX, and raw CAN can combine multiple inputs. Modbus FC16 shows each register range. S7 has a single-value write form. Optional confirmation can show the destination and values.
- **Periodic tasks.** Buttons and data send cards use their individual intervals and read current inputs or committed project parameters each cycle. The runtime task view shows destinations, counts, and skipped cycles and lets you stop jobs across pages.
- **Project data.** Use shared readings and parameters in displays, curves, records, alarms, and commands. Set a data validity period and inspect source, sample time, and quality in the monitor. Displays and curves can also bind template fields directly.
- **Digital timing chart.** Use a status word or bind individual channels to CAN signals or project data points on one time axis. Unavailable channels leave gaps. Set a custom time window, inspect values with a cursor, import and export CSV or JSON, and record changes automatically to CSV.
- **Series 17 labs.** Thirteen projects cover TCP, UDP, virtual serial, virtual CAN, Modbus, and MQTT. Exercises include feedback, mixed frames, invalid frames, and stopping periodic sends.

### Fixes and improvements

- Organize properties into General, Actions and sending, and Receiving and binding. Control visibility follows the current mode. Switches can distinguish explicit on and off feedback.
- Validate routes and endpoints before a send. Indicate ambiguous sources, stale values, and conversion failures. Apply the readings in a frame before evaluating alarms. Remote write controls avoid incidental writes to a local Modbus slave.
- Preview the impact of a receive template change and migrate references to fields that remain available. Clear an obsolete endpoint when switching connections.
- Preview references affected by an inline CAN signal rename and update unambiguous references on confirmation. Reject conflicting assignments to overlapping bits in the same CAN frame.
- Update visible CAN monitor rows when returning to a tab. Batch receive log refreshes on a 40 ms timer. Auto-scroll pauses when reading older rows and resumes at the bottom. Preview and exported apps remember log display preferences independently.
- With both receive logs present, the 17.10 loopback test decoded all 180,000 frames at 6,000 frames per second over 30 seconds and observed zero periodic sends after stopping the task.

### Upgrade from v0.8

Studio v0.9.0 reads UIDP 1.0–1.3. Frame templates, new send settings, and periodic configurations use UIDP 1.3. Check input-only and read-only fields, command routes, selector options, and record columns when opening existing projects. Set the send card's format to CAN for manual CAN traffic. Export an existing standalone app again to bundle the v0.9 runtime.
