# 向设备发送命令

[v0.9 使用手册](../guide.zh.md) · [UIDP 工程格式](../uidp-format.md)

在 FluentHMI Studio 中，把 `commandMode` 和发送属性写在控件的 `properties` 中。一个控件的动作决定何时发送，所选模式决定线上字节。

在设计器的「操作与发送」中配置发送模式、连接和命令。[连接和子通道](data.md#连接与子通道)

| 控件 | 发什么、何时发 |
| --- | --- |
| `PushButton` | 点击发送 `command`，或合并「输入列表」里的当前值。Modbus 的单项参数用 `mbValue` 设置读取数量、开关状态或写入值 |
| `ToggleSwitch` | 用户拨动时发送 `onCommand` 或 `offCommand`。Modbus 模式下，`mbArea` 为 `"线圈"`（默认）时用 FC05 写开/关，为 `"保持寄存器"` 时用 FC06 写 `1` / `0`，为 `"保持寄存器位"` 时按 `mbBit`（`0`–`15`）先读出寄存器再只改该位写回 |
| `Slider`、`SpinBox` | 开启「变化时向设备下发」（`sendOnChange`）后发送已提交的值。滑块在松手时发送，数值框手输后按回车或离开输入框时发送。步进操作每步提交 |
| `LineEdit` | 按回车发送输入值。开启「仅输入」时，回车只结束输入，按钮可以读取其当前值并统一发送 |
| `ComboBox` | 开启 `sendOnSelect` 后，选择一项就发送该行 `options` 中的 `value`。值留空时使用显示名称 `label` |
| `DataSendCard` | 点击发送或按回车，发送输入框中的文本、HEX 或原始 CAN 帧 |

下拉框、滑块和数值框的发送开关适用于所有发送模式，包括 Modbus 和 S7。

旧工程中只读的输入框继续只读，已保存的回读绑定可继续更新显示。文本、HEX、JSON 和 CAN 输入框缺少发送开关或关闭了回车发送时，按「仅输入」加载。手写 UIDP 时使用 `inputOnly: false` 明确启用回车发送。

## 发送预览与下发确认

发送预览先解析目标连接及子通道。Modbus 显示实际采用的 TCP、ASCII、RTU、RTU over TCP 或本机从站表。日志中的设备应答属于协议层结果，设备状态由绑定的回读点更新。

1. 选中控件，在「操作与发送」选择目标连接并设置命令。点击「发送预览」核对编码结果。开关分别展示开和关的命令，输入控件可填写示例值。
2. 需要人工确认时开启「下发前确认」（`confirmBeforeSend`）。在运行预览或导出的应用里触发控件时，点击「确认发送」才会下发。弹窗初始焦点在「取消」，直接按回车会取消本次操作。
3. 需要在确认时核对命令，再开启「确认时显示详情」（`showSendConfirmationDetails`）。两个选项默认关闭，详情选项随下发确认显示。

Modbus 预览显示功能码、从站、地址和参数，运行时按连接封装 RTU、TCP 或 ASCII。CAN 预览按目标连接的 DBC 和信号定义核对报文及值。

Modbus 自动匹配和广播会按功能码与从站地址筛选本机从站表。读请求由通信连接发送，需读取本机从站表时可以直接绑定寄存器。

例如用开关写 Modbus 保持寄存器 10，在「发送预览」核对 FC06 和开／关的写入值 1／0。启用详情后，在运行时也可在确认弹窗核对目标连接、从站和地址。按 v0.9 的设置运行预览，导出时随附同一版本的运行器。

## 周期发送

选中按钮或数据发送卡片，在「操作与发送 → 发送间隔」填写 `1` 到 `60000` 毫秒。设为 `0` 时使用该控件原有的发送方式。文本、HEX、JSON 和 CAN 命令沿用各自的连接和编码设置，输入列表、模板字段和工程数据点也可以作为发送内容。

运行时点发送按钮开始，启用「下发前确认」时确认一次。绑定输入框、模板字段或工程数据点的按钮每轮取当前有效值并重新组帧。数据发送卡片在运行中可以直接编辑内容，下一轮自动读取。固定命令每轮发送原配置的内容。

输入不符合发送配置时跳过该轮，可在「周期任务」查看原因。输入恢复有效后自动继续。独立输入框直接提供当前内容。绑定工程参数的输入框按回车或离开字段后提交参数，周期任务读取项目中已提交的有效值。

首次提交前，按钮显示「取消启动」。运行中可点原按钮停止，也可在预览工具栏或导出应用底部打开「周期任务」，跨分页查看目标、间隔、提交和跳过次数，并停止所选或全部任务。「停止所选」会清空选择，继续停止其他任务时需先选中对应行。

目标断开或改变、退出运行预览和关闭应用都会停止。链路忙时跳过当前轮次，释放后从后续轮次继续。停止会取消后续轮次，已提交给链路或适配器的帧可能完成。重连后可手动再开始，运行中的任务不随工程保存。

间隔存为 UIDP 1.3 的 `properties.sendIntervalMs`。同一 CAN 连接的同一标准／扩展 ID 共享一个周期。手动启动等适配器确认首帧后接管 `canCycle` 或 DBC 周期。运行中可改载荷，更换 CAN ID 要先停止再启动。同一报文的另一个手动周期会提示占用，单次写入其他不重叠的 DBC 信号仍可合入发送缓存。试用步骤见 [17.10 周期混发](../tutorials/17-frame-io.zh.md#1710-同连接多接收模板)。

## 一个按钮合并多个输入

1. 选中按钮，在「操作与发送」选择模式和连接，打开「编辑发送配置」。
2. 在同一窗口新建输入框，或从「选择已有」直接挑选控件。新建的输入框在确定时出现在按钮所在页面，默认开启「仅输入」。HEX 和 CAN 原始数据的各项数据类型就在输入列表中选择。
3. 配置输入时自动生成模板，可通过「自动生成」重新排布当前草稿。文本和 JSON 可以在光标处点选插入变量。HEX 和 CAN 可调整字段顺序、插入固定段，也可用「模板文本」粘贴现有模板。底部用示例值显示编码结果。
4. 确定后一次保存输入和发送配置。开启「下发前确认」后，运行时弹窗列出本次取到的值。确认发送使用同一批值。

| 按钮发送模式 | 输入和格式 |
| --- | --- |
| 文本 | 多个输入可填入 `KP={p1},KI={p2}` 等模板。可设置换行符 |
| JSON | 多个输入可填入 `{"kp":{p1},"ki":{p2}}` 等模板。变量占一个完整的 JSON 值位置，合法 JSON 保留类型，普通文本自动转义并加引号。已有的单值 JSON 项目可点「沿用已有输入列表」启用多输入 |
| HEX | 重排固定字节和多个输入，设置帧头、帧尾、字节序、长度和校验 |
| CAN | 原始数据可设置各项类型、字节序、长度和校验。定义了信号的报文按 DBC 或内置信号布局赋值 |
| Modbus | FC16 按列表顺序写连续寄存器。其他功能使用界面中的固定值或绑定一个输入，按功能码解释为读取数量、线圈状态或寄存器值 |
| S7 | 使用固定写入值或绑定一个输入，按所选地址和 S7 数据类型编码 |

可以直接编辑模板，用花括号引用变量。变量名区分大小写，以英文字母或下划线开头。多输入使用 UIDP 1.3，按钮的 `commandInputs` 记录输入控件 ID、模板变量和数据类型。S7 和单值 Modbus 分别使用 `s7InputId` 和 `mbInputId`。

## 发送帧的长度与校验

在控件的「操作与发送」或按钮的「编辑发送配置」中，可以选择工程「发送帧模板」。HEX 和原始 CAN 载荷使用模板的帧头、帧尾、长度与校验，文本和 JSON 使用模板的编码与结束符。控件的命令、输入列表和发送内容保存在控件上。原始 CAN 的 ID 由发送配置指定，手工发送卡片从 `ID#载荷` 取 ID。

模板引用存于 `properties.sendFrameTemplateId`。选择「独立配置」可编辑控件自己的帧格式。[工程帧格式模板](connections.md#工程帧格式模板)

### 按模板字段发送

在「数据与报警 → 帧格式模板」编辑字段，可为 `cmd` 设置「发送默认值」，例如 `1`。按钮配置和回车发送会共用该值。某个按钮需要不同的 `cmd` 时，可以在该按钮上设置固定值覆盖。

在按钮的「编辑发送配置」选择 HEX 帧模板，点「按字段填写」。找到 `rpm`，在「值来源」选择一个输入框，或选中该行后点击「为所选字段新建输入框」。运行时在输入框填写 `1500`，点击按钮即可组帧。若只需回车发送当前输入框的值，可以在输入框属性里选同一模板，并把「发送字段」设为 `rpm`。需要传入整段载荷时，点「整段 HEX」，可填写固定内容或选择已有输入框，模板仍会计算帧长和校验。

字段沿用模板里的偏移、数据类型和字节序。控件明确设置的字段优先，其他字段使用模板默认值。勾选「发送时必填」后，如果既无默认值也无控件提供的值，点击按钮或在输入框按回车都会提示缺值字段并停止发送。控件覆盖值留空也会提示，数值 `0` 可以发送。按字段组帧时，未赋值的匹配命令字自动补齐，其他剩余载荷字节填 `00`。原始 HEX 输入保留已填写的字节，预览会指出与接收匹配条件的差异。长度字段和校验自动计算，字段的字节范围和预览报文使用对应的颜色。此配置适用于 HEX 发送和原始 CAN 载荷。

UIDP 1.3 中，HEX 模板的 `parserConfig.sendDefaults` 按字段名保存默认值，例如 `{"cmd":"1"}`，`parserConfig.sendRequiredFields` 列出必填字段，例如 `["rpm"]`。按钮用 `sendUseTemplateFields: true` 启用字段取值，`sendFrameFieldBindings` 的每一行保存字段和输入来源，例如 `{"field":"rpm","inputId":"rpmInput"}`。按钮上的固定值覆盖写成 `{"field":"cmd","value":"2"}`。直接发送控件用 `sendFrameField` 指定字段名。

在 HEX 按钮的「编辑发送配置」中切到「多模板混发」，可依次添加工程模板。选中列表中的一帧即可绑定输入或设置固定值。各帧独立组帧，按列表顺序拼入同一次发送。周期发送时每轮读取当时的输入值。任一帧有必填字段缺值时，整轮不会发送。UIDP 1.3 用 `sendFrameSequence` 保存有序列表，各项包含 `sendFrameTemplateId` 与 `sendFrameFieldBindings`。

Modbus 和 S7 发送控件可选可写设备数据点作为「写入对象」。连接、地址和数据类型沿用该点的配置，并在「实际写入目标」中显示。Modbus 线圈对应 FC05，保持寄存器可用 FC06 或 FC16，带位号（`mbBit` 为 `0`–`15`）的保持寄存器数据点用 FC06 按位读-改-写。FC16 写入列表沿用数据点的起始地址和寄存器序，首项类型须与所选数据点一致。对 UDP 和 TCP 服务端，写入使用数据点指定的子通道，或当前有效反馈确认的对端。

数据发送卡选用工程 HEX 模板后，可点「按字段发送…」，输入各字段并核对组帧结果。字段默认值、必填和校验规则沿用模板。周期任务运行时可编辑已选字段的值，下个周期组帧时生效。

多模板混发和按数据点写入均沿用 UIDP 1.3。保存时用 `sendConfiguration` 保存所需的发送配置。旧版 Studio 打开时该动作会停用，以免按残留的连接或原命令下发。

按钮在「编辑发送配置 → 长度与校验」设置规则。开关、下拉框、输入框、滑块、数值框在 HEX 或原始 CAN 模式下也可打开「发送帧格式」。各入口使用同一组长度、校验规则与组帧逻辑。数据发送卡可在 HEX 模式下配置同样的规则，填写载荷后自动补上帧头、长度、校验和帧尾。帧格式留空时，发送卡直接发送输入的 HEX 字节。

在 HEX 或 CAN 原始数据的发送配置中，点选「长度与校验」。修改时仍可查看输入列表和发送示例。

发送示例为每个字节标注整帧偏移。帧头、长度、固定段、输入项、校验和帧尾用不同的颜色区分，点选配置或字节可以相互定位。点「复制 HEX」可把完整示例贴到接收端的解析预览。[接收帧预览](connections.md#hex-二进制帧)

- **固定帧长**校验组帧后的总字节数。长度不符时预览和下发会报错。
- **长度字段**在给定偏移插入 1 或 2 个长度字节，偏移从帧首按 0 开始计数。长度可表示数据、长度字段之后的全部字节，或整帧。「数据」计算长度字段之后、校验和帧尾之前的字节。
- **校验**可选和校验、异或、CRC8、CRC16-Modbus、CRC16-CCITT。起始字节从帧首按 0 编号，计算到校验字段前一字节。预览用橙线标出参与计算的字节，并显示生成的校验值和写入位置。两个字节的校验可设置结果的字节序。

例如帧头 `AA 55`，数据 `10 22 30`，帧尾 `0D`。在偏移 2 插入 1 字节数据长度，并从偏移 3 算异或，发送结果为 `AA 55 03 10 22 30 02 0D`。

CAN 原始数据的长度和校验作用于应用数据，CAN FD 的 DLC 补齐由发送链路完成。Modbus 的 RTU CRC、ASCII LRC、TCP 长度和 S7 的协议封装由各自链路生成。这些发送帧规则存储在按钮的 `txFrame`，沿用 UIDP 1.3。

## 一个按钮写入多项 Modbus 参数

FC16 配置的每行显示占用的寄存器范围与示例值。从地址 100 开始写三个 `float32` 时，范围依次为 100–101、102–103 和 104–105。列表包含双寄存器类型时才需要设置寄存器序。输入来源可选已有输入框或工程数据点，当前需要现场输入的参数也可在此新建输入框。

S7 写入在一个表单中设置连接、地址、类型和单值来源。可填固定值、引用输入框或选用工程数据点。

1. 选中「写入 PID」按钮。在「操作与发送」选择 Modbus、目标连接、从站地址和「16 写多个寄存器」。将寄存器地址填为第一项的协议地址，例如 `100`。
2. 打开「编辑发送配置」，按设备的寄存器顺序添加 Kp、Ki、Kd 三行并选择数据类型。三项均为 `float32` 时，依次占用 100–101、102–103 和 104–105，整条请求写 6 个寄存器。32 位值共用按钮的「寄存器序」。
3. 开启「下发前确认」。运行时填好参数再点击按钮。开启「确认时显示详情」还能核对从站、起始地址和每项类型。

下例为按钮的 `properties`，三个 `inputId` 需对应输入框的控件 ID。`commandInputs` 为空时，FC16 使用按钮自身的单个「写入值」设置。

```json
{
  "text": "写入 PID",
  "commandMode": "Modbus",
  "commandTargetId": "plc",
  "mbSlave": 1,
  "mbFunc": "16 写多个寄存器",
  "mbAddress": 100,
  "mbRegOrder": "大端(AB CD)",
  "commandInputs": [
    {"inputId": "Kp", "dataType": "float32"},
    {"inputId": "Ki", "dataType": "float32"},
    {"inputId": "Kd", "dataType": "float32"}
  ],
  "confirmBeforeSend": true
}
```

## 控件配置示例

开关、滑块和数值框可以通过绑定写回本地 Modbus 从站表。控件执行远端下发时优先使用下发设置。在无下发动作时，指定一个本地从站作为绑定来源即可写回该表。绑定带转换表达式时只回读。

下拉框的选项名和发送值一起编辑。以下配置显示「停机」和「运行」，默认选停机。`currentIndex` 和回读选中值使用从 0 开始的序号。

```json
{"options": [{"label": "停机", "value": "0"}, {"label": "运行", "value": "1"}],
 "currentIndex": 0, "sendOnSelect": true}
```

| `commandMode` | 编码 |
| --- | --- |
| `"文本"`（默认） | 将 `commandTemplate` 中的 `{value}` 替换为当前命令或值。例如 `SPEED={value}` 发出 `SPEED=75`。末尾的 `commandNewline` 可选 `"无"`、`"\\r\\n"`（默认）、`"\\n"`、`"\\r"`，这里按 JSON 文件中的转义方式书写 |
| `"HEX"` | `dataType` 为 `"HEX字符串"` 时直接使用 HEX 文本（如 `01 03 00 00`）。数值类型按 `dataType`、`byteOrder` 打包后放进模板，可以加 `frameHeader` / `frameTail` |
| `"JSON"` | `{value}` 占一个完整 JSON 值的位置。例如模板 `{"cmd":"setSpeed","value":{value}}` 可以产生 `{"cmd":"setSpeed","value":75}`。输入是合法 JSON 值时保留类型，普通文字自动转义成字符串。编码后按 `commandJsonNewline` 加结尾，默认 `"无"` |
| `"Modbus"` | `mbSlave`、`mbFunc`、`mbAddress` 指定从站、功能码和地址。按链路封装 RTU、TCP 或 ASCII。读操作填写数量。`"05 写单线圈"` 输入 `1` 写开（`0xFF00`），输入 `0` 写关（`0x0000`）。`"06 写单寄存器"` 可写 `uint16/int16`，设置 `mbBit`（`0`–`15`）时按位读-改-写（按钮通过 `mbBitAction` 选 `"置位"`、`"复位"` 或 `"取反"`）；`"16 写多个寄存器"` 还可写 `uint32/int32/float32`。32 位值占两个寄存器，`mbRegOrder` 决定寄存器序。按钮的 `mbValue` 可按所选类型填写数值文本，例如用 `"25.3"` 写入 float32 |
| `"CAN"`（FluentHMI Studio） | DBC 信号与原始报文的命令见 [CAN 总线](can.md) |

例如下面是一个滑块的 `properties`。用户将滑块调到 75，松手时设备收到一行 `SPEED=75`。

```json
{"minimum": 0, "maximum": 3000, "sendOnChange": true, "commandTargetId": "serial1",
 "commandMode": "文本", "commandTemplate": "SPEED={value}"}
```

普通字节命令发往已连接的相应链路。MQTT 发布到 `defaultPublish`，UDP 发送数据报，两者都会保留命令的换行设置。设备需要整条消息恰为 `ON` 时，将 `commandNewline` 设为 `"无"`。

开关读写保持寄存器时，在「操作与发送」选择 Modbus 和「写入区」保持寄存器，填写从站和写入地址。在「接收与绑定」选择 Modbus 和「读取区」保持寄存器，填写读取地址与从站过滤。地址从 0 开始。设备用同一地址控制和回读时，两处填写同一地址。

「接收与绑定」中的「状态判定」（`onCondition`）默认 `"非零为开"`，回读 `0` 显示关，非零显示开。选 `"等于指定值"` 后，可填写「开启判定值」（`onValue`，默认 `"1"`）和「关闭判定值」（`offFeedbackValue`，默认留空）。关闭判定值留空时，匹配开启值显示开，其余有效数值显示关。

例如设备用 `1` 表示开、`2` 表示关、`3` 表示故障，开启判定值填 `1`、关闭判定值填 `2`。收到 `3` 时保留当前开关状态。两个判定值应使用不同的数字，可使用负数、小数和数字文本。无效读数或无效判定值会保留当前状态。转换表达式先执行，再与判定值比较。回读只更新开关状态，用户拨动时才执行写入或触发切换通知。Modbus 保持寄存器写入仍为开 `1`、关 `0`。
