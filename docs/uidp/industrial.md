# 工业设备与仪表

每个工业控件使用下表中的 `type`。常规卡片默认 160×140，三位四通换向阀默认 245×155，最小尺寸均为 80×72。三端的软件自带矢量图和活动部件，工程保存数据绑定、位置和配置。

汽车电子、电子 DIY 和嵌入式控件的单位和量程也按下表填写。接收数组、对象和共享位定义的控件有专门的字段。[电子控件类型表](electronics.md) · [共享位定义与复合反馈](electronics.md#共享位定义与复合反馈)

## 六项共有属性

| 属性 | 含义 |
| --- | --- |
| `title` | 图上方的标题，默认为表中的中文名称。 |
| `unit` | 工程单位。原始数据需换算时，在 `binding.expression` 里换算后设置单位。 |
| `value` | 设计时的示意值。运行时等待第一条设备反馈，实际读数不写回工程。 |
| `minimum`、`maximum` | 连续量刻度端点。图形限在量程内，读数保留实测值。 |
| `decimals` | 数值读数的小数位，0–6。 |

下面的数字压力表读取从站 1 的保持寄存器 100–101，按大端字序解析 `float32`，以两位小数显示压力（MPa）。在属性面板「数据绑定」的最后一行可以填写转换表达式。状态量也能复用表达式，例如 `(value >> 2) & 1` 提取运行位。[解析和转换表达式](data.md)

```json
{
  "type": "PressureGauge", "id": "outlet_pressure",
  "geometry": {"x": 20, "y": 120, "w": 215, "h": 185},
  "properties": {"title": "出水压力", "unit": "MPa", "decimals": 2},
  "binding": {"parseMode": "Modbus", "mbArea": "保持寄存器", "mbSlaveFilter": 1,
              "mbRegIndex": 100, "mbDataType": "float32", "mbRegOrder": "大端(AB CD)"}
}
```

## 状态和专有选项

- 运行时，第一条匹配数据到达前显示「待数据」。非有限数或未定义的状态码显示「数据异常」。下一条有效反馈恢复显示，其他设备的数据不会覆盖当前读数。开关命令和实际设备反馈各用自己的控件。
- `PressureGauge`、`Tank`、`Voltmeter` 和 `Ammeter` 可设 `showLimits`、`lowLimit`、`highLimit`。上下限采用显示单位，下限小于上限时生效。达到边界也会显示限值提示。水箱默认启用 20% 和 80%，电压表默认启用 340 V 和 420 V。压力表预置 0.2 和 1.2 MPa，电流表预置 0 和 80 A，均可手动开启。
- `FlowPipe` 的 `pipeShape` 选 `"弯管"` 或 `"直管"`，`pipeDirection` 选 `"正向布局"` 或 `"镜像布局"`，`pipeWidth` 为 8–26，默认 16。流量过零时箭头换向，零流量时停下。
- 电机和气缸还有 `feedbackMode` 属性。电机默认 `"转速"`，有符号 rpm 指示方向。选 `"运行位"` 时反馈 0 为停止、1 为运行。气缸默认 `"行程"`，选 `"端位状态"` 时 0 表示两端均未确认，1 表示缩回，2 表示伸出，3 表示冲突。两端均未确认时隐藏活塞位置。
- `FlowTotalizer` 直接显示仪表累计读数，复位后跟随设备回到零。`PowerMeter` 默认正值为输入，负值为输出，现场约定相反时可用 `-value`。`StackLight` 以位 0、1、2 表示绿、黄、红，反馈 5 同时点亮绿灯和红灯。
- `DirectionalValve` 显示三位四通换向阀的实际位置。反馈 0 点亮封闭的中位，1 点亮 P→A、B→T，2 点亮 P→B、A→T。P 和 T 是供给和回流口，A 和 B 是工作口。

## 可直接运行的示例

全景工程按用途展示工业仪表、工业设备、汽车电子、电子 DIY 和嵌入式控件。「反馈模式」页还可对照电机运行位、气缸端位和不同布局的管道。用 HMI 或 Python 打开工程，在示例目录运行 `python3 replay.py --port 8766 --frames 动态反馈.jsonl`，再点「动态回放」的连接。顶部显示当前阶段，每两秒切换，依次覆盖正反转、量程两端、状态组合、无效输入与恢复。[动态控件全景](../../examples/industrial/动态控件全景.uidp) · [反馈数据](../../examples/industrial/动态反馈.jsonl)

网页独立演示可直接选择同一组反馈帧。在网页「自定义设备」编辑器里打开工程时，用装有 PyQt5 的 Python 运行 `python replay.py --web --port 8767 --frames 动态反馈.jsonl`，在通信卡片中连接 `ws://127.0.0.1:8767`。这两个端口可同时使用。

打开[恒压供水泵站](../../examples/industrial/恒压供水泵站.uidp)，TCP 卡片沿用供水教程的默认地址。压力和流量分别读保持寄存器 100、102（各占两个寄存器）。104 用 `value * 0.1` 换算 Hz，105 是液位。线圈 0 和 1 分别是两台泵的运行反馈，线圈 2 对应整站故障灯。

没有 PLC 时可打开[工业控件回放](../../examples/industrial/工业控件回放.uidp)。在工程所在目录运行 `python3 replay.py`，在 HMI 或 Python 预览里点「本机回放」的连接。用本地网页时，在装有 PyQt5 的 Python 环境运行 `python replay.py --web`，用相同的工程连接 `ws://127.0.0.1:8765`。每个连接从第一帧开始，每两秒切换一次，依次展示正向、停止、反向、超限、故障、无效输入与恢复。按 Ctrl+C 结束。[回放程序](../../examples/industrial/replay.py) · [模拟反馈帧](../../examples/industrial/反馈回放.jsonl)
