# FluentHMI Studio v0.9 使用手册

[English](guide.en.md) · [项目首页](https://github.com/txp666/FluentHMI-Studio) · [安装与部署](build.zh.md) · [v0.9.0 更新说明](release-notes/v0.9.0.md)

Studio 用来搭建设备监控和调试界面。一个工程可以同时连接多个设备，分别设置接收来源和发送目标。先在运行预览里核对报文和设备反馈，再把已验证的工程导出为独立应用。

## 第一次运行

1. 安装适合系统和架构的 Studio。界面语言在「设置 → 语言」中切换，重启后生效。[安装包与平台要求](build.zh.md#安装)
2. 打开 [17 数据收发与帧模板](../examples/tutorials/17-数据收发与帧模板.uidp)。在「预览运行」启动预览，先连接右侧模拟设备的 TCP 服务端，再连接左侧上位机。两端默认使用 `127.0.0.1:39172`。
3. 将目标转速填为 `1500`，点「发送转速」。在确认窗口核对目标和值，点「确认发送」。右侧应显示设备收到的目标转速。
4. 点右侧「回送设备反馈」并确认。左侧显示 `1500 rpm`，曲线增加一个采样点。将输入改为 `2300` 后按回车，再回送一次。切到记录表页，可核对两次目标值。
5. 打开「工程数据监视」，核对设备点的来源、质量和采样时间。右侧报文卡可检查实际收发字节。[实训中的完整报文和排错步骤](tutorials/17-frame-io.zh.md#17-入门共用一份帧模板)

## 从空工程搭建一条收发链路

这个练习使用同一工程中的两张 TCP 卡，无需硬件。设备报文采用 `rpm=1500\n`，接收端将 `rpm` 显示为一个数值。

| 放到画布上的控件 | 在属性区填写 |
| --- | --- |
| TCP 卡 `hmi` | 默认模式选「客户端」，地址 `127.0.0.1`，端口 `39190` |
| TCP 卡 `device` | 默认模式选「服务端」，地址和端口与客户端相同 |
| 输入框 | 「操作与发送」选文本，目标是 `hmi`，模板填 `rpm={value}`，换行符选 `\n`，关闭「仅输入」 |
| 数据接收卡 | 来源连接选 `device`，用于查看收到的原始报文 |
| 数值显示 | 「接收与绑定」选来源 `device`，解析模式选「键值匹配」，绑定字段填 `rpm`，单位填 `rpm` |

两张 TCP 卡可跟随工程的文本解析设置。运行预览后依次连接服务端、客户端，在输入框输入 `1500` 并回车。确认接收卡出现一条带 `rpm=1500` 的记录，数值卡显示 `1500 rpm`。若端口已占用，在连接前给两端设同一个空闲端口。

继续添加实时曲线时，可把 `device` 的 `rpm` 存为工程数据点。数值显示和曲线改选「工程数据点」，绑定同一个点。要模拟回读，把另一按钮的发送连接设为 `device`，发送模板同样写 `rpm={value}` 并关联设备侧数据点，另一个显示控件从 `hmi` 取数。[数据点与参数配置](uidp/alarms.md#数据点)

## 配置连接与收发方向

为每条物理连接或逻辑连接放一张连接卡。配置卡片 ID 后，再在控件的「接收与绑定」指定来源，在「操作与发送」指定目标。标题用于显示，控件 ID 用于引用。

| 链路 | 在连接卡上先设什么 | 常用练习 |
| --- | --- | --- |
| 串口 | 端口、波特率、数据位、校验位、停止位和流控。内置虚拟串口 A/B 在同一运行工程中成对连接 | [17.11 虚拟串口双向收发](tutorials/17-frame-io.zh.md#1711-串口收发与数据发送卡) |
| TCP | 客户端连服务器地址和端口。服务端在本机地址监听。服务端有多个客户端时，按子通道选择对端 | [17.10 多模板混收](tutorials/17-frame-io.zh.md#1710-同连接多接收模板) |
| UDP | 两端的本地端口与对方的目标端口配对。按发送方地址和端口筛选来源 | [17.2 嵌套 JSON](tutorials/17-frame-io.zh.md#172-udp-嵌套-json) |
| MQTT | Broker 地址、端口、订阅和发布主题。用来源子通道区分收到的主题 | [17.12 发布订阅](tutorials/17-frame-io.zh.md#1712-mqtt-发布订阅与主题取值) |
| CAN / CAN FD | 卡型号、设备和通道、标称速率。CAN FD 再设数据域速率。使用 DBC 时导入对应文件 | [CAN 位时序与信号](uidp/can.md) |
| 经典 S7 | IPv4 地址、端口、机架、插槽和连接类型。绑定时再填写绝对地址和类型 | [13 S7 联调](tutorials/13-s7-plc.zh.md) |

留空发送连接时，只有一个兼容目标才会自动匹配。多个连接或 TCP 服务端有多个客户端时，指定连接和子通道。需要同时发送到多路时显式选择广播。日志卡和监视器可以汇总来源。工程数据点用于计算、报警或发送时，给它设置可唯一识别的来源。[连接与子通道规则](uidp/data.md#连接与子通道)

## 共用帧格式模板

1. 在「数据与报警 → 帧格式模板」新建 HEX 或文本／JSON 模板。HEX 模板填写分帧方式和校验，再增加命令字及数据字段。文本模板可配置编码、分隔符和结束符。
2. 在可视化编辑器粘贴一条完整报文。彩色字节条和字段表可以相互定位。切换到「位图」可按 `B7` 到 `B0` 查看每个字节，选中字段会高亮对应的位。字节条上的蓝色虚线表示长度范围，橙色实线表示校验覆盖。字段表中偏移从帧头后起算，预览里的字节位置、校验起始位置和长度字段位置从整帧第 0 字节起算。
3. 保存模板。在连接卡选择「接收帧模板」。需要在同一条流上混收时用「多选…」，为各模板定义可区分的帧头或命令字。组内的分帧和校验按照各自模板执行。
4. 在显示控件、曲线或工程数据点选择来源连接，再选「按模板字段取值」。例如混收工程里三个模板都有 `value`，分别选 `speed.value`、`temperature.value`、`status.value`。字段定义和当前控件的转换表达式分别保存。
5. 在按钮的「编辑发送配置」或输入框的「操作与发送」选择同一发送模板。按钮可把多个字段关联到输入框、工程数据点或固定值。输入框按回车发送时选一个「发送字段」。`cmd` 可在模板里设默认值，`rpm` 可设发送必填。改字段名或类型时先看影响范围，确认改名后会更新可确定的字段引用。

例如 `AA 55 03 10 DC 05 C5`。`03` 表示后续数据 `10 DC 05` 占 3 字节，包含命令字 `10`。`DC 05` 按小端 `uint16` 是 `1500`。在 17.9 的规则下 CRC8 覆盖 `03 10 DC 05`，得到 `C5`。[帧配置、覆盖范围与样例](uidp/connections.md#hex-二进制帧)

## 发送、确认与周期任务

| 要完成的操作 | 设置入口 |
| --- | --- |
| 回车发一个值 | 输入框的「操作与发送」。设置发送模式和目标，检查「仅输入」为关闭 |
| 一个按钮发多个值 | 「编辑发送配置」中新建输入框或选已有输入。用文本／JSON 模板、HEX 字段或 CAN 原始载荷组织内容 |
| 确认后下发 | 开启「下发前确认」。再开「确认时显示详情」时可核对目标、输入值和命令。两项默认关闭 |
| 一次写多项 PLC 参数 | 按钮选 Modbus FC16，每行选择值来源和数据类型，核对起始地址及逐行寄存器范围。S7 用单值写入表单 |
| 定时重复发送 | 按钮或数据发送卡设置「发送间隔」，单位毫秒。运行时点开始，再点原控件可停止 |

先点「发送预览」核对连接、地址和编码，再到运行预览实际下发。周期任务每轮读取当前输入。工程参数在回车或离开字段后提交，周期发送读取已提交的有效值。缺少必填字段时跳过该轮，恢复值后继续。可在预览工具栏或导出应用底部打开「周期任务」，跨页查看和停止任务。断开目标或退出运行会清理任务。[命令模式、触发条件与周期规则](uidp/commands.md)

## 工程数据与报警

在设计器顶部打开「数据与报警」。把需要多处使用的设备读数保存为数据点，控制参数使用「工程参数」，组合状态使用「计算表达式」。例如将两张卡的故障分别保存为 `A故障`、`B故障`，总故障表达式填写 `T["A故障"] or T["B故障"]`。给设备点设置数据有效时间后，可在运行预览的工程数据监视区分旧值、来源不唯一和换算失败。

1. 新建报警规则，选择数据点和阈值。可用「按阈值生成条件」生成表达式。
2. 在画布放报警栏或报警列表。运行后可确认、消音或切换历史。报警条件回到正常和操作员确认会分别记录。
3. 在历史页展开「筛选」，选级别、事件和时间。自定义时间支持 Fluent 日历、独立时分秒选择和键盘输入。可导出筛选后的结果或全部历史。

用 [14 工程数据与报警](../examples/tutorials/14-工程数据与报警.uidp) 练习。启动 `9201` 和 `9202` 两路本机 TCP 服务端，设备 A 发 `fault=0,soc=65`，设备 B 发 `fault=0`，每条以换行结束。任一来源把 `fault` 发成 `1` 会触发总故障，把 `soc` 降到 `20` 会触发低电量。[工程数据与报警参考](uidp/alarms.md)

## 分页导航与控件外观

分页容器可以选经典选项卡、下划线导航、分段导航或文档页签。「当前编辑页」决定画布正在修改哪一页，「运行时启动页」决定预览和独立应用打开哪一页。在属性区添加、改名、重排各页。普通属性、下发和接收配置分别按组显示，选项变化后显示适用字段，信息按钮提供示例。

数值显示可切换状态徽标，映射如 `0=停止`、`1=运行|#107c10`。动力电池开启「电量分段变色」后设低电量和预警上限。数值框、选择器及开关也有多种外观。试用 [15 分页与控件风格](../examples/tutorials/15-分页与控件风格.uidp) 和 [16 输入与状态筛选](../examples/tutorials/16-输入与状态筛选.uidp)。

在「数字时序图」属性选择「逐路绑定」后，用「当前编辑通道」为每路选择 CAN 信号或工程数据点。运行时可用时间窗下拉框设自定义时长，点文件夹图标导入时序记录，点保存图标手动导出或开启自动记录。导入后点「回到实时」可继续看实时信号。用全景工程的「信号与诊断」页练习查看波形。[动态控件全景](../examples/industrial/动态控件全景.uidp) · [时序图设置与文件格式](uidp/electronics.md#共享位定义与复合反馈)

## 核对报文与排错

| 现象 | 在 Studio 中怎么查 |
| --- | --- |
| 连接成功但读数没更新 | 数据接收卡先看是否收到，再核对来源连接、子通道、模板字段和字节序 |
| 有线路字节但没有完整报文 | 开启「线路字节」，看组帧等待或丢帧原因。点一条记录再点「试解析所选」，核对实际长度和校验 |
| 同名字段混到同一个数字里 | 给接收绑定选明确的连接和子通道。对同一连接的多模板组使用 `模板ID.字段` |
| 点击控件没有下发 | 用发送预览核对目标和地址。查看必填字段、仅输入、下发确认及通知内容 |
| 周期发送仍显示旧值 | 独立输入检查当前内容，工程参数按回车提交。到周期任务列表查看本轮值和跳过原因 |
| CAN 只想改一个输出位 | 核对设备的控制帧和反馈帧。支持相同位布局时，在连接卡设初值映射，例如 `HMI=IO`，发送模板按信号赋值，例如 `B4b4={value}`。[首帧反馈映射](uidp/can.md#发送与监视) |

接收卡按约 40 ms 批量刷新，保留上限内的最新日志。解析和数据点按报文到达处理。自动滚动开启时，上翻暂停跟随，返回底部恢复。格式、线路字节和自动滚动偏好在已保存工程的预览与独立应用中分别记住。需要完整 CAN 记录时，用报文监视的自动保存，把 CSV 分段写入目录。[CAN 自动保存](uidp/can.md#多通道与自动保存)

## 保存、导出与升级

保存 `.uidp` 后从 Studio 导出独立应用。主题、强调色和语言来自导出时的设置，工程的 DBC 和图片随应用复制。应用使用同一运行逻辑，可把导出产物复制到适用的平台和架构。[平台部署与导出命令](build.zh.md#导出独立应用)

Studio v0.9.0 打开 UIDP 1.0～1.3。工程级帧模板、周期任务配置和新发送属性以 UIDP 1.3 表达。升级旧工程时，应核对原输入框的只读或禁发、发送目标、下拉选项和记录列。使用新版功能的工程以及已导出的独立应用，用 v0.9.0 运行或重新导出。[工程格式与旧版迁移](uidp-format.md#从旧版升级)
