# Classic S7 connections in Studio v0.9

[使用手册](guide.zh.md#配置连接与收发方向) · [User guide](guide.en.md#connections-and-routing)

Add an **S7 connection card**, set the PLC IPv4 address, port, rack and slot,
then connect in Preview. The default port is 102; FluentPLC Simulator examples
use 1102. Automatic connection is off by default. Connection type values are
1 (PG), 2 (OP), and 3 (S7 Basic).

For a display or chart, choose **S7** as its binding/curve mode, select the
source card by ID, and enter an absolute address and data type. A period of zero
uses the connection card's default poll period. Different cards remain isolated,
even when they read the same address.

Supported addresses are `DB1.DBX0.1`, `DB1.DBB2`, `DB1.DBW12`, `DB1.DBD4`, and
the corresponding `M`, `I`, and `Q` bit/B/W/D addresses. Types are `BOOL`,
`BYTE`, `SINT`, `WORD`, `INT`, `DWORD`, `DINT`, and `REAL`, in Siemens big-endian
order. Address widths must match the selected type. The input area `I` is read-only.

For an output control, choose the **S7** command mode and its target card.
A button uses `s7Command.value` or one input selected by `s7InputId` in its write form.
A switch sets its write values in `s7Command.onValue` and `s7Command.offValue`. Text inputs send their value when the operator presses Enter.
Bind a label or numeric display to show the PLC readback. Sliders, spin boxes and
combo boxes send their runtime values when their send option is enabled.
A switch's display condition `onValue` remains independent of its nested command
values. Device feedback never echoes a write.

BOOL writes use the native S7 bit operation and preserve adjacent bits.
Writes are serialized with reads. A write timeout is reported as an unknown
outcome and is not retried. Reconnection resumes reads without replaying writes.
Bad or disconnected samples retain the last display value and mark its quality.

An engineering project with S7 alone uses UIDP 1.1. Routing, frame templates,
project data, and newer send features can require UIDP 1.2 or 1.3.
[Project format and version selection](uidp-format.md).

The same S7 client runs in Preview and exported applications, with the native
library and license materials included in each package.

This implements classic S7comm over ISO-on-TCP. S7-300/400 are the primary targets;
S7-1200/1500 require firmware/configuration that permits PUT/GET and non-optimized
global DB access. Optimized DBs, symbolic access and S7CommPlus are not supported.
Local simulator validation does not establish compatibility with every real PLC.

Open the [S7 demo](../examples/s7-demo.uidp) for a manual connection to a local simulator.
